# Angular frontend

Minimal standalone application shell. Run `npm ci`, `npm run format:check`, `npm run build` and `npm test` here using Node 24 LTS. See [local development](../../docs/local-development.md).

No login flow, client secret, token persistence or API call exists. `identity.config.example.json` documents public future OIDC settings and is not bundled or consumed by the shell.
