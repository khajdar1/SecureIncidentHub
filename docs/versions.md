## Dependency purpose and license review

Microsoft hosting/JWT/MVC test packages are MIT; Angular/Node/Prettier/jsdom/Vitest are MIT; TypeScript/RxJS/OpenTelemetry/xUnit are Apache-2.0; tslib is 0BSD. PostgreSQL uses the PostgreSQL License, RabbitMQ MPL-2.0, AWS provider MPL-2.0, Gitleaks MIT and Trivy Apache-2.0. These identifiers were checked from official source/package metadata before adoption. Terraform 1.15 uses [BSL 1.1](https://github.com/hashicorp/terraform/blob/v1.15.9/LICENSE); retain awareness of restrictions if the project's use changes to a competing hosted service. No project license is invented on the owner's behalf.

Avoid adding storage/messaging/ORM SDKs before their adapters exist. No browser OIDC library is added yet. Installed dependency licenses are available in npm package metadata and NuGet package license files. Vulnerability checks are recorded in the Phase 0 verification report; support status and zero known findings are not security guarantees.

Initial machine inventory: .NET 9.0.305, Node 22.14.0/npm 10.9.2, Docker 29.1.3/Compose 5.0.1, Terraform 1.15.3, AWS CLI 2.34.38, Git and Python 3.13. Gitleaks/Trivy and PowerShell 7 were absent. Verification used ignored, checksum-verified `.tools` downloads of the selected SDK/Node/Terraform/scanners; system installations were not upgraded. Windows PowerShell 5.1 is supported by the scripts; CI uses PowerShell on Linux.
